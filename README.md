A premium, high-fidelity professional portfolio showcase engineered for high performance and visual excellence. This project blends the precision of a Martial Artist with the vision of a Technologist into an immersive digital ecosystem.

## 🚀 Key Features

- **Bento Grid Architecture**: A modern, responsive dashboard-inspired layout.
- **Glassmorphism UI**: High-end dark theme with blurry backgrounds and vibrant accent colors.
- **SEO Optimized**: Fully integrated with JSON-LD structured data, Open Graph tags, and Twitter Cards.
- **Performance Driven**: Lazy loading, async image decoding, and `content-visibility` optimizations for instant load times.
- **Project Archive**: Interactive showcase featuring first-person narratives for FinAIMT, Dojo System, and more.
- **Certification Hub**: A dense, gallery-style hub displaying professional achievements with custom lightbox support.

## 🛠 Tech Stack

- **Core**: HTML5, Vanilla JavaScript
- **Styling**: Vanilla CSS (Custom Grid & Flexbox)
- **Metadata**: JSON-LD, Open Graph, Twitter Metadata
- **Icons**: FontAwesome 6.4

## 🔧 Performance & SEO Specs

- **Image Optimization**: `loading="lazy"`, `decoding="async"`
- **Critical Path**: Font-display: swap, Preconnect & DNS-prefetch for external assets
- **Google Search**: Person Schema (JSON-LD) for better indexing
